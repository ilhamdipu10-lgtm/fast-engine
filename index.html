    Cara pakai

    1. Buat website: isi nama, lalu tekan Buat website.
    2. Siapkan folder website. File utama wajib bernama index.html.
    3. Di laptop, seret folder ke kotak upload. Di HP atau tablet, jadikan satu file ZIP lalu tekan Pilih ZIP.
    4. Setelah selesai, tekan Buka.
    Kenapa file utama harus bernama index.html?

    File index.html adalah halaman yang pertama terbuka saat orang mengunjungi alamat websitemu. Huruf besar dan kecil tidak dibedakan.

    Berapa ukuran maksimal website?

    Sementara 20 MB per upload, dan tiap file maksimal 20 MB. Kecilkan foto sebelum upload supaya muat.

    Foto atau CSS saya tidak muncul

    Pastikan nama file di kode sama dengan nama file di folder, misalnya img/foto 1.jpg. Huruf besar dan kecil tidak dibedakan, spasi boleh. Jangan pakai tanda ? atau # di nama file. Alamat berawalan garis miring seperti /img/foto.jpg di HTML dan CSS otomatis diarahkan ke websitemu. Di JavaScript, pakai alamat tanpa garis miring di depan, misalnya img/foto.jpg.

    Cara upload dari HP atau tablet (file ZIP)

    HP dan tablet tidak bisa memilih satu folder utuh, jadi jadikan folder websitemu satu file ZIP dulu. Di iPhone dan iPad: buka aplikasi Files, tekan lama folder, lalu pilih Compress. Di Android: pakai aplikasi pengelola file yang punya menu Kompres atau Compress. Setelah itu tekan Pilih ZIP dan pilih file ZIP-nya.

    Tampilan website tidak rapi di HP

    Taruh baris ini di bagian head setiap halaman: <meta name="viewport" content="width=device-width, initial-scale=1">

    Bisakah website menyimpan data di browser pengunjung?

    Tidak. Demi keamanan, website berjalan di lingkungan terisolasi, jadi localStorage, cookie, dan IndexedDB tidak tersedia.

    Apa yang terjadi kalau saya upload ulang?

    Seluruh isi lama diganti dengan yang baru. Kalau upload gagal di tengah jalan, isi lama tidak berubah dan jatah upload hari itu tidak terpakai.

    Bagaimana cara mengganti nama atau menghapus website?

    Di daftar Website saya, tekan Ganti nama atau Hapus di baris website itu. Ganti nama mengubah alamat websitenya, jadi alamat lama tidak bisa dibuka lagi. Hapus menghapus website beserta semua filenya dan tidak bisa dibatalkan. Untuk mengganti isi website, cukup upload ulang.

    Cara mengganti ikon (favicon) dan judul tab website saya

    Masukkan gambar ikon ke foldermu, misalnya favicon.png (persegi, 64 x 64 piksel atau lebih), lalu tambahkan di bagian head setiap halaman: <link rel="icon" href="favicon.png">. Judul tab diatur dengan <title>Nama Tokomu</title>. Kalau kamu tidak memasang ikon, browser menampilkan ikon fast-engine.

    Berapa kali saya boleh upload per hari?

    Free 1 kali, Premium 5 kali, Pro 10 kali per hari. Hitungannya per akun (semua websitemu digabung) dan kembali penuh setiap pukul 00.00 WIB. Upload yang gagal tidak mengurangi jatah.
